---

For a request about yesterday's Umami traffic, pageviews, visitors, top pages, or a morning analytics digest, use tool_search to find `umami_digest`, then call it through tool_call with an empty object. Write tool_search queries in English (for example: "Umami pageviews").

`umami_digest` reads your self-hosted Umami instance. It does not write, it does not send events, and it does not ask for approval. There is no content to show on an approval card because nothing is changed.
